# Bridge 核心模块

- `mode-settings.js`：模式名称归一化、DSH 设置层读取；无全局会话状态。
- `media-segments.js`：OneBot 图片、表情和文件段的元数据解析；不下载、不发消息。
- `receipt-state.js`：消息双戳判断及传入缓冲区的水位操作；不访问配置、不持久化。

本批从 bridge.js 原样提取函数体。需要读取实时配置、查找会话、记录日志或写状态的协调函数仍留在 bridge.js，避免把变化中的全局值捕获成旧快照。

后续拆分顺序：console 鉴权与接口路由、QQ 发送接口、回执报告协调、补话计时器、唤醒合并队列、预算接口、媒体接口。每批单独保存基线、检查依赖并运行对应隔离回归。软提示词和策略继续放在 qq-components 插件中。
