# skill：每日工作总结（life-daily-worklog）

## 它解决什么
「今天到底干了什么」汇总自独立当前事务及修改历史、任务会话与运维账本；会话事实与展示日记各有职责。
事务优先读取 state/memory/affairs/*.json；旧 tasks Markdown 仅供迁移前日期的历史日报读取，迁移动作不冒充当天完成的工作，通知收据不算任务进度。
本插件每天固定时间把散落的运行数据汇总成一份**可回溯的 Markdown 日报**。

## 什么时候被调用
`onTick`：插件宿主每 60 秒触发一次。只有满足下面条件才真正干活：
- 已过当天配置的 `hour:minute`（默认 23:00），或桥接重启后发现**昨天**的日报缺失；
- 对应 `state/memory/worklog/<日期>.md` 不存在；
- 同一个日期两次失败尝试间隔 ≥ 30 分钟（`state/plugins/life-daily-worklog.json` 记录）。

## 数据来源（只读）
| 来源 | 内容 |
| --- | --- |
| `state/memory/tasks-*.md` | AI助手收尾前用 `qq_task_note` 记的中期进度（按当天日期过滤） |
| `state/tasks.json` | `qq_task_spawn` 开的任务会话（标题/状态/结果摘要） |
| `state/tool-calls.jsonl(.1)` | 当天工具调用次数、失败次数、TOP 工具 |
| `state/token-usage.jsonl(.1)` | 当天模型调用步数与输入/输出 token（按会话、按模型） |

## 日报生成规范（2026-10-29 替换版）
根据当天的任务进度、任务会话、工具调用、token 账本、自我更新与修复摘要、反馈队列事件，生成面向用户的每日工作总结。
让用户快速看懂今天做了什么、取得什么结果、还有什么问题；不要把事件流水当成工作成果。

短报固定采用以下结构：
1. **概览**：保留任务会话总数及完成/失败/进行中、工具调用及失败次数、模型调用步数与输入/输出 token、反馈新增/修复/删除与困难列表流转数量。输入注明包含缓存命中；统计来源不可读时写“未采集”，不得当作 0，不推算费用。
2. **今日主要成果**：按事项归并，通常 3—5 条，有几条写几条；说明处理的问题、当前变化及验证/应用阶段。同一事务的多轮修改只保留当天最新状态。不得凭会话完成推断功能完成，也不得凭隔离测试通过推断已上线或真实使用已验证。长描述压缩时保留“尚未部署”等限制。
3. **未完成与后续**：列仍影响使用、尚未验证、进行中、失败或需要用户决定的事项，简述影响与下一步；没有明确记录时说明证据限制，不凑条目。
4. **反馈与修复**：不重复概览统计，不逐条罗列编号、时间和队列流转。当前组件只收集事件元数据，因此明细留在完整记录，不臆造反馈问题、剩余数量或修复效果，不复制私人反馈原文。
5. 结尾始终保留 `完整记录：state/memory/worklog/<YYYY-MM-DD>.md`。

使用简洁、自然的中文，不写没有具体结果的“全面提升、持续优化”等话术。
工具失败不等于任务失败；只根据任务结果报告影响，不擅自宣称失败已经恢复。
短报目标 600—900 字，现有管理端有 900 字发送边界，因此实际正文最多 880 字。
先生成完整短报再检查长度：超长时减少次要条目、压缩单条描述；保留概览、关键成果、待办、反馈说明和归档入口，禁止截取整份报告的前 N 字。
当前生成器为确定性模板，不调用 LLM；上述规范由 `summary.js` 实现，不声称进行了模型语义审查。

## 产物
- `state/memory/worklog/<YYYY-MM-DD>.md`：完整归档，保留进度历史、任务结果、反馈事件和详细统计，不受发送长度截断。
- 定时发送与控制台手动发送使用同一短报生成器，归档本身不直接当作短报发送。
- 当天完全没有数据时不写文件（30 分钟后重试）。

## 配置（plugin.json 的 config）
- `hour` / `minute`：生成时间，默认 23:00（本地时区）。
- `sendToOwner`：生成后是否把摘要发到管理员 QQ，默认 `false`。
- `maxChars`：短报预算上限，实际发送还受 880 字正文上限约束；不截断完整归档。

## 边界
- 只读运行数据，只写 `state/memory/worklog/` 与自己插件目录下的状态文件；不碰永久记忆目录里的其它文件。
- 不改唤醒计划、不发群消息；`sendToOwner` 走桥接的 `notifyOwner` 能力（owner 私聊）。
- 日报是**数据汇总**，不替代永久记忆；是否要把它注入提示词由后续需求决定。
