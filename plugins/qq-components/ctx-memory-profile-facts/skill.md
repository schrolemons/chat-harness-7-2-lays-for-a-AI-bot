# skill：用户画像记忆（profile-facts）

## 一句话
把「这段对话里谁说了什么值得记住的」交给 AI 判断，插件只负责攒素材、控频率、写提示词。

## 什么时候被调用
- 每收到一条来信：`onIncoming` 把文本压进待处理队列（默认最多 12 条，跨会话一起排队）。
- 每次拼唤醒提示词：有当前会话素材就及时提供给模型整理，默认不再额外冷却；只有值得长期使用的稳定事实才写入。
- 每 30 分钟：`onTick` 清掉超过 6 小时的旧素材，防止越攒越多。

## 人物档案固定四部分
- **作息与饮食**：只记本人明确表达的稳定三餐、口味、起床/入睡、工作/上课时间；时间写入 `facts.routines` / `facts.workWindows`，饮食偏好写 `facts.likes` / `facts.dislikes`。仅保存在本人 `private:<QQ>`，不跨会话、不进群。
- **兴趣与爱好**：本人明确表达或反复表现的稳定兴趣写 `facts.hobbies`；非饮食偏好/雷点写 `likes` / `dislikes`。单次提及不能推断为长期爱好。
- **人际关系**：`profile_update` 只把档案对象本人和他人的关系，或本人表达的互动边界写入 relationships 字符串。不得把关系对象自己的作息、饮食、爱好、性格、经历等写进目标档案；也不记录第三方传闻、机器人指令或猜测。
- **口头禅**：`facts.quotes` 仅记录本人反复使用且有稳定辨识度的表达；单次原话、金句、辱骂或临时玩笑不属于口头禅。
- 近况、当天情绪和一次性安排留在当前会话轻量记忆，不进入人物档案。只记本人明确表达或多次一致提及的事实，不从在线时间、语气或玩笑推断。

当前发言者明确表达的稳定信息写入按 QQ 号保存的 JSON 人物档案：`profile_update({ userId, key, profile })`。固定键为 `routine_food / hobbies / relationships / catchphrases`，值为字符串并允许增加新键；作息饮食只在本人私聊上下文自动注入，群聊通过 `profile_get` 按本轮发言者读取四个固定键。
对本轮没有发言的其他成员，只把临时印象写入本会话轻量记忆：`qq_memory_append(category="memberImpression", extra.target="那个人", content="简短印象")`；它不会同步到人物档案。
同一条事实只写入一个位置；不要把猜测、一次性情绪或普通玩笑记成稳定画像。

## 边界
- 不做正则抽取、不猜；素材原话保留，判断交给模型。
- 不记录联系方式、证件、地址、账号密码（写入侧还有一层脱敏闸门）。
- 每个会话只看到自己的素材，不把别的会话私事混进来。

## 调试
- 状态文件：`state/plugins/profile-facts.json`（`pending` / `lastAskedAt`）。
- 插件清单：`GET /api/plugins`（需控制台令牌）。
