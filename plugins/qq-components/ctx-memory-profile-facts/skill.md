# skill：用户画像记忆（profile-facts）

## 一句话
把「这段对话里谁说了什么值得记住的」交给 AI 判断，插件只负责攒素材、控频率、写提示词。

## 什么时候被调用
- 每收到一条来信：`onIncoming` 把文本压进待处理队列（最多 6 条，跨会话一起排队）。
- 每次拼唤醒提示词：`beforePrompt` 若距上次提问超过冷却（默认 10 分钟）且当前会话有素材，
  就把素材 + 字段口径写进提示词，标记已提问。
- 每 30 分钟：`onTick` 清掉超过 6 小时的旧素材，防止越攒越多。

## 字段口径（AI 落库时用）
- 称呼：对方希望被怎么叫 / 明确不让叫的
- 喜好：爱吃、爱看、在追、在玩
- 雷点：讨厌什么、别说什么
- 近况：最近在忙/在做的具体事
- 名言：原话金句（用引号）
- 作息：只有本人明确分享的三餐（时间＋口味）、起床/入睡、工作/上课时段，写入 `facts.routines`（短句或对象 `{ time, exactness: "固定"|"大致", taste }`）；工作时段也可写 `facts.workWindows`，或直接用 `facts.breakfast/lunch/dinner/wake/sleep`。标记“大致/固定”，更正时替换旧值。作息仅限对应私聊，不跨群/会话分享，不从在线时间推断。
- 口味：爱吃甜/辣、不吃什么，写 `facts.likes` / `facts.dislikes`（食物相关的短句），人物卡「作息」块会汇总成「口味」一行单独可查。

当前发言者明确表达的稳定信息写入人物小档案：`profile_record_facts({ userId, name, key, facts })`，字段为 `aliases / likes / dislikes / recents / quotes / routines / workWindows`。作息只在与该用户的私聊提示词中呈现为固定「作息」块；到点附近可顺口贴合一句，不催吃饭/催睡觉、不假定对方有空、刚聊完不叠加，临时变动写当前会话轻量记忆而不覆盖稳定作息。
对本轮没有发言的其他成员，只把临时印象写入本会话轻量记忆：`qq_memory_append(category="memberImpression", extra.target="那个人", content="简短印象")`；它不会同步到人物档案。
同一条事实只写入一个位置；不要把猜测、一次性情绪或普通玩笑记成稳定画像。

## 边界
- 不做正则抽取、不猜；素材原话保留，判断交给模型。
- 不记录联系方式、证件、地址、账号密码（写入侧还有一层脱敏闸门）。
- 每个会话只看到自己的素材，不把别的会话私事混进来。

## 调试
- 状态文件：`state/plugins/profile-facts.json`（`pending` / `lastAskedAt`）。
- 插件清单：`GET /api/plugins`（需控制台令牌）。
