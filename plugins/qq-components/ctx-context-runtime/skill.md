# ctx-context-runtime

按会话事实生成参与度和时间感提示；参与度只服务群聊，不把“群里冷清、少说话、潜水”的建议塞进私聊。维护回合不注入，不自主调用模型。

时间感以近期原文和未完成队列中的最新人类来信为准；旧未完成记录不能盖过刚收到的新消息。10/120分钟等阈值只提醒时效与口吻，不授予主动机会、不凭时间强制结束，不禁止获准的主动回合延续上一段话题；不把bot自己的起床、在线时间当成用户作息。原始消息与收据不因此改写，结束由等待工具endRound决定。

时间感实现位于time-sense.mjs；组件热加载时辅助模块携带相同版本查询，避免重载后仍沿用旧提示。src/context-runtime.js只保留参与度统计，移除旧时间感实现，不保留双入口。

插拔、配置和验收参见 docs/guides/PLUGIN_RUNTIME_CONTRACT.md。运行 npm run test:plugin-audit，测试使用隔离文件和模拟端点。
