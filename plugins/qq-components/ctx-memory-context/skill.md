# ctx-memory-context

格式化会话事实/今日画像、当前事务、窗口轻量记忆；QQ稳定人物档案由独立组件注入。宿主按1200字分片，单插件总量上限8000字。

轻量记忆包含当前话题、待说想法和当前小上下文窗口内实际发言用户的行为印象；不注入窗口外成员，也不因同一个人再次出现就复活其旧窗口印象。内容有持续价值才提炼为会话有源事实。普通聊天不注入日记，昨日画像不冒充今日观察。

`maxChars` 限制会话事实与画像注入（最低500）；本轮宿主预算更小时取更小值。`affairsMaxChars` 限制完整事务条目选择（最低200），不再读取旧 midTermSlice 或原始 tasks 尾部。组合上限预留余量，事务按剩余预算重选；未带入内容仍保存，可用 qq_task_note list 查看。首次切换须协调 core/MCP 更新，之后参数修改由控制台热加载生效。

插拔、配置和验收参见 docs/guides/PLUGIN_RUNTIME_CONTRACT.md。运行 npm run test:plugin-audit，测试使用隔离文件和模拟端点。

当前事务的注入优先级紧随窗口轻量记忆，先于持久事实。普通聊天每轮复核相关现有事务，按稳定ID更新进度和下一步；完成、取消、替代须有用户原话或工具结果依据，不以沉默或时间流逝自动结案。无证据时保留等待，相关时自然确认，避免重复新增或反复追问。
