# 自动回复消息过滤

正文去除开头空白后，以 `[自动回复]` 开头的 QQ 入站消息直接丢弃，不调用模型、不发送回应，也不进入待答队列。私聊与群聊使用相同规则，包括当前已有活跃回合的会话。

判定只拼接当前消息自身的 text 段，忽略引用内容、@昵称和附件；没有结构化消息时才使用原始文本。正文中间提及该标记、引用自动回复后附上正常文字，均按普通消息处理。

过滤在桥接入口执行，早于已读回应、媒体解析、预算来信计数、主动唤醒和其他消息副作用。不新增每日次数状态，不修改历史消息和已经安排的正常消息回应。

拥有源为本组件的 `incomingFilter.evaluate` 服务；桥接只分发事实并执行返回的拦截决定。首次接入入口需重启桥接，后续组件策略改动可热加载。

隔离验证：`npm run test:incoming-filter`。
