# ctx-context-session

角色、身份、状态和首次初始提示词；停用后协议令牌仍由环境信封保留。

当前角色与实际 QQ 昵称是身份事实；历史自我介绍、群友绰号不改变角色，也不自动变成自我介绍的别名。保留原始聊天与角色卡，不用改写历史解决旧称呼复现。

status块同时提供交互事件事实：近期窗口按真实seq去重，区分最新文字/媒体消息与结构化拍一拍，明确尚未回应和已回应的拍一拍seq。空@和点名不产生poke；唤醒原因的重复注入不代表再次拍了一拍。该模块属于逐请求刷新的当前会话状态，不持久化新账本、不修改收据，不改角色卡。

插拔、配置和验收参见 docs/guides/PLUGIN_RUNTIME_CONTRACT.md。运行 npm run test:plugin-audit，测试使用隔离文件和模拟端点。

状态块可从milkStock.context读取管理员私聊专属账户余额快照，标明核对时间与过期/失败；群聊及其他私聊不注入。仅动态事实，不改角色卡或额度策略。
