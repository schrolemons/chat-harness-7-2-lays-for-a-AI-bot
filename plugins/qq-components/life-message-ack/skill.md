# life-message-ack

L 层未回复补话配置组件。私聊等待、私聊抱歉、群聊等待、群聊抱歉四组分别控制启用状态、延迟和固定话术表；两组延迟从最新完整用户消息进入桥接时起算。进入回复流程就立即布点，不等待合并窗口、新 prompt 接受或现有回合结束，首次会话、排队、思考和工具等待均适用。新消息先作废旧轮，再按最新消息重新布点；正式回复在实际调用 QQ 发送接口前取消两组，排队和准备发送不取消。旧回复若在新消息到达后才返回发送成功，不影响新消息的计时。等待语录本身不会取消道歉语录，同一轮最多各发送一次。输入框中未发送的文字不会触发，未进入回复流程的额度静默、未授权或免打扰消息不发补话。

通过 `messageAck.plan({ key })` 服务按会话类型返回各组配置与随机话术。bridge 把独立延迟注册到 `life-scheduler`，并负责会话状态校验、发送队列与实际投递。

设置由 console 的插件配置接口保存，保存后热重载此组件，不需要重启 bridge。
