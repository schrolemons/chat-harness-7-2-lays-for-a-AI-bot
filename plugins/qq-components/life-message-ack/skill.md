# life-message-ack

L 层未回复补话配置组件。私聊等待、私聊抱歉、群聊等待、群聊抱歉四组分别控制启用状态、延迟和固定话术表；延迟从本批合并窗口结束后起算。每条完整 QQ 消息进入桥接时取消该会话旧计时器，只有最新且符合唤醒条件的消息能重新布置补话。输入框内尚未发送的文字不会触发；同一批补话最多发送一条话术。

通过 `messageAck.plan({ key })` 服务按会话类型返回各组配置与随机话术。bridge 把独立延迟注册到 `life-scheduler`，并负责会话状态校验、发送队列与实际投递。

设置由 console 的插件配置接口保存，保存后热重载此组件，不需要重启 bridge。
