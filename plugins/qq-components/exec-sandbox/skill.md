# skill：执行后端声明（exec-sandbox）

## 它解决什么
执行环境的选择以前只写在提示词里，容易记错边界。这个插件把可用后端与边界做成可查询的声明。

## 工具
- `exec_backends()`：列出后端（id/默认模式/审批/可碰范围/适用场景）。
- `exec_pick({ task })`：按任务类型推荐后端（write-repo / run-local / read-web / send）。

## 四个后端
| id | 场景 | 边界 |
| --- | --- | --- |
| dsh-workspace | 默认工作区 | 仅会话工作区可写 |
| dsh-full | 仓库外/state/、重启进程 | 需说明理由，先备份 |
| admin-dev | owner 本机运维 | 自动放行，但仍拒绝凭据外发/越权 |
| browser-cdp | 真实 Edge 登录态 | 禁支付/银行/身份验证 |

## 边界
这个插件只声明与推荐，不代理执行；真正的沙箱与审批在 DSH 与桥接。
