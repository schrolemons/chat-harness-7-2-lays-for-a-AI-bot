# 可视化 context

O 层最终编排：`enabled/order/disabled/compactHistory` 是全局 context 规则，不修改原组件开关或工具授权。组件拥有源不变。受保护模块不可屏蔽；固定角色进入系统层，会话背景进入用户附加资料，事实保持 user 数据身份。

装填 v2：系统硬规则与角色卡原文稳定；当前心情、形态和完整风格示范改为后置状态资料，不再拼入角色卡。稳定会话背景/协议及心情行为规则放进 user 前缀。所有投影保留原事件，不改 `roles/*` 正文，不改变事实与用户原话的权限。

每个 pre-step 使用原签名包向本机 `/api/context/refresh` 请求最新组件资料，绑定会话及当前 nonce，不需要控制台凭据。只刷新 REFRESH_MODULE_IDS 中已核对的心情、会话事实、记忆/画像、日程和时间约定拥有源；不重跑会消耗冒泡次数或 pending 任务的接纳钩子。稳定人物档案放 user 前缀，临时画像仍为动态资料。桥接只提供事实与按 ID 选择组件的环境能力，不新增业务判断；伪造、跨会话和过期批次拒绝。失败沿用上次可靠状态，并在实际请求证据中明确标为 stale。检查器的 inspect 不走这个刷新通道，不调用钩子或 LLM。

动态资料按组件内容哈希比较，只追加变化和明确撤回；未变化不重复注入。旧状态保留为历史，同组件以最后更新为准。压缩后缺失的状态重新提供，稳定资料更新仅作原生 surface replacement，工具调用/返回不重排。软配置、原始聊天数据都不提升为新系统权限。preset 与 bridge 核心变动需按 AGENTS.md 的授权流程加载，不能把网页刷新当已生效。

`contextAssembly.compose` 接收真实本轮模块、写入脱敏证据，接收端完成会话就绪确认后才发送签名包。`inspect` 仅投影已捕获模块，不执行业务钩子、不调用 LLM。未采集的会话明确显示无证据，不编造预览。

DSH 的 `qq-agent-presets/context-composer.mjs` 使用正式钩子处理入箱、系统装配及 pre-step。通过 surface replacement 收缩重复包装，引用原事件；不删除日志，不改工具调用配对。`llm/stream` 只观察实际请求。令牌与签名不进入控制台或 Git。

token 数值由字符粗估，实际费用以供应商账单与令牌台账为准。全局设置在下次唤醒生效；当前正在生成的请求不变。

保留39个来源槽位，36号内部拆分收件状态与新增聊天并关联启停，39号整体为任务说明。实际请求保持原顺序，按系统、稳定资料、聊天与工具、动态更新筛选；工具定义独立 tools 字段。动态卡说明当前/历史/撤回，组件入口能定位当前值所在消息。同一持续处理保留初始/上次/当前请求，旧记录保持旧口径，缺证据不推断。observerVersion=5、layoutVersion=2。
