# 可视化 context

O 层最终编排：`enabled/order/disabled` 是全局 context 规则，不修改原组件开关或工具授权。组件拥有源不变。受保护模块不可屏蔽；固定角色进入系统层，会话背景进入用户附加资料，事实保持 user 数据身份。

表达优先修复（2026-10-31）：系统硬规则与角色卡原文保留，受信组件签名包中当前选定的形态、风格及完整示范作为独立表达分段进入系统上下文，撤下动态资料中的同一份表达。角色原文与表达分段可分别追溯；O 层屏蔽动态组件时也撤下其表达，重排不重复注入。心情分数、会话背景、用户原话和记忆仍为 user 资料，不能借此提升权限。所有投影保留原事件，不改 `roles/*` 正文。

每个 pre-step 使用原签名包向本机 `/api/context/refresh` 请求最新组件资料，绑定会话及当前 nonce，不需要控制台凭据。只刷新 REFRESH_MODULE_IDS 中已核对的心情、会话事实、记忆/画像、日程和时间约定拥有源；不重跑会消耗冒泡次数或 pending 任务的接纳钩子。稳定人物档案放 user 前缀，临时画像仍为动态资料。桥接只提供事实与按 ID 选择组件的环境能力，不新增业务判断；伪造、跨会话和过期批次拒绝。失败沿用上次可靠状态，并在实际请求证据中明确标为 stale。检查器的 inspect 不走这个刷新通道，不调用钩子或 LLM。

每次请求只在业务消息末尾放一份完整当前资料。以前由qq-context-update/qq-context-latest标记的状态节点从模型可见投影退役，原始事件不删除；不扫描任意聊天正文。工具调用/返回保持原顺序与配对。DSH的工具注册变更属于协议记录，可能位于业务资料之后，必须按实际位置显示。软配置和原始聊天不提升权限；预设重载遵守部署授权。

`contextAssembly.compose` 接收真实本轮模块、写入脱敏证据，接收端完成会话就绪确认后才发送签名包。`inspect` 仅投影已捕获模块，不执行业务钩子、不调用 LLM。未采集的会话明确显示无证据，不编造预览。

DSH 的 `qq-agent-presets/context-composer.mjs` 使用正式钩子处理入箱、系统装配及 pre-step。surface replacement 仅更新稳定资料或退役已被替代的当前背景，不再扫描、精简旧格式历史包；不删除日志，不改工具调用配对。`llm/stream` 只观察实际请求。令牌与签名不进入控制台或 Git。

C36 `message-snapshot` 独占当前收件状态索引。每次已验证签名的请求刷新时，桥接只返回模型窗口内的收件元数据；组件仅更新原窗口 seq 的索引，不借此接入新聊天正文，不写已读或回复戳，也不消耗发送额度。seenAt、repliedAt、receiptState 等实际字段保留，稳定说明与当前索引分开装填。历史工具调用与返回维持原顺序，不能作为第二份当前索引。Console 将无正文状态行折叠在 C36 内；聊天与工具使用单列时间线，缺失原始 seq 不补造编号。

token 数值由字符粗估，实际费用以供应商账单与令牌台账为准。全局设置在后续模型请求生效；当前正在生成的请求不变。

保留40个来源槽位（C40为按需注入的私人资料；可视化context是管理设施，不发送给AI），36号内部拆分收件状态与新增聊天并关联启停，39号整体为任务说明。实际请求保持原顺序，按系统、稳定资料、聊天与工具历史、本次输入与处理任务、当前补充资料筛选；工具定义独立 tools 字段。动态卡说明当前/历史/撤回，组件入口能定位当前值所在消息。同一持续处理保留初始/上次/当前请求，旧记录保持旧口径，缺证据不推断。observerVersion=6、layoutVersion=3。

查看界面采用“系统上下文、稳定用户上下文、聊天与工具历史、本次来信与处理任务、当前补充资料（历史后注入）”，提供与酒馆的概念对照及组件职责说明，不把对应关系当作实际权限或装配改动。等待工具返回独立展示判定、行动建议与 QQ 消息；C10 请求前建议与超时后的工具建议明确分开。采集兼容 DSH 顶层 toolCallId 与旧内容块配对格式；旧采集缺失的配对可只读从原生日志恢复，失败不推测，不读出隐藏推理或额外工具正文。


会话工具授权：角色名与身份属于稳定资料，会话令牌属于每次请求末尾的 ctx-context-session 当前状态。空闲回合结束或重置后桥接会轮换令牌；模型不得复用历史调用或压缩摘要中的旧值。刷新失败时可保留描述性状态，但撤下缓存令牌，等待有效授权恢复；鉴权不放宽，旧令牌仍拒绝。生成预设的唯一守卫引用由 scripts/build-agent-preset-patches.mjs 定义为 qq-agent-presets/qq-tool-restrict.mjs，不能重新生成已移除的 phi 壳。

同一回合的处理要求在工具返回后仍是持续目标，不代表新来信或重新执行命令。逐请求资料刷新包含 ctx-chat-reply-shape 的真实成功/待确认/剩余进度；该钩子只读账本，不重算或授予额度。实际 QQ 验收曾发现工具已成功但模型对同一图换说法重发，补充持续目标标识与实时进度后，同场景复验只发一条并结束。原工具结果与配对仍保留。
