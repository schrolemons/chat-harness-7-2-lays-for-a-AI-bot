# 网站监督与脚本协同

管理员可用 web_watch_status 查看已配置网站的读取、登录、变化和通知状态，以及已登记脚本的心跳。脚本登记只用于协同和状态展示，执行仍由开发者显式安排。没有配置网站时不启动检查任务。
## 登录队列和访问错误恢复

另一个网站的登录窗口运行期间，新网站的等待登录状态仍会保留。原窗口结束且监控租约空闲后，Bot 调度优先接续已配置网站的等待登录请求，不受全量检查冷却阻挡，也不新增失败计数。有头窗口聚焦真实登录页后关闭专用浏览器中的多余空白标签。

普通访问失败与认证失效分别处理；持续访问失败按配置间隔提醒，状态保留到对应页面恢复。只有用户在 anonymousHttpFallbackUrls 中逐条指定的无认证 HTTP 网页才允许匿名静态读取回退；默认关闭，不携带登录凭据，不允许跨站重定向，不把空白或登录页当作页面更新。

监管对象是用户自行配置的任意网页，不预设校园网站、课程或报告接口。Cookie、本地存储和会话存储只能尽力恢复；二维码、MFA、短时令牌或不可复用的登录仍需用户完成。是否恢复以目标页面重新访问验证为准，不以 Cookie 存在、窗口打开或统一认证页跳转作为成功证据。
