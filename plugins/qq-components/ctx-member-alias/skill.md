# skill：成员绰号表（ctx-member-alias）

## 它是什么
维护「绰号 → QQ号」的映射，让小鲸鱼知道群里谁是谁。

## 流程
1. **刷新候选**：控制台单次刷新会补扫允许的近期群消息，并最多提取一个候选。优先收录明确自称或明确说明称呼归属；疑似邀约、问询对象、@成员后的短称呼可留空 QQ 进入人工判断。模糊场景必须有至少两位不同发言者的独立消息将同一短称呼用于同一成员，且置信度达标。整句、黑话解释、辱骂或性内容均不能作为绰号证据。宁缺毋滥。
2. **校验证据**：候选称呼须原样出现在引用原文且短于等于12字。只有 QQ 来自唯一可核验的群成员身份时才绑定；其他情况留空，绝不把发言者当作被称呼者。
3. **人工审核**：管理员可编辑候选的绰号和 QQ、确认或拒绝；一个 QQ 可有多个独立绰号。拒绝记录会阻止相同来源重复提交。
4. **AI 可访问**：每轮提示词注入已确认的「成员绰号速查」表；只有确认项可用于称呼或 @。`qq_alias_query` 查询，`qq_alias_submit` 提交候选；自动化不能确认候选。

## 工具
- `qq_alias_query`：按绰号或 QQ 查询确认映射
- `qq_alias_submit`：提交明确或疑似候选，可不带 QQ
- 管理员控制台：查看、编辑、刷新（抓取+语义提取+合并）、确认或拒绝候选
- 可在控制台手动添加；自动识别也保留，编辑与审核使用统一学习卡片交互。

## 边界
- 只做映射与速查，不改变白名单/权限/发送对象；传话仍走 life-relay-message。
- 候选保留原始上下文供管理员审核；确认项按“绰号+QQ”独立保存，最多 200 条。
