# skill：全局用户画像（profile-store）

## 它解决什么
让「谁是谁、聊过几次、喜欢什么、讨厌什么」跨会话有效，而不是每个会话各记一份、换个群就全忘。

## 什么时候被调用
- **收消息**（`onIncoming`）：记身份（userId/昵称）、出现过的会话、互动次数、最后出现时间。
- **拼提示词前**（`beforePrompt`）：只产出【别处听来的（可分享）】；当前发言者的稳定档案由「人物小档案」组件唯一注入。
- **被工具调用**：`profile_record_note` / `profile_record_facts` / `profile_promote_impression` / `profile_snapshot`（走 `/api/plugins/call`）。
- **跨组件服务**：`routineSlots`（把稳定作息换算成定时冒泡槽位）、`routineCard`（返回固定「作息」块文本与单独的口味，只对本人私聊 key 生效）。

`profile_promote_impression` 只接受 24 小时内该群真实发言者的 QQ 号，并校验原印象目标是该用户已知昵称。它将印象和非数值型 `warmConnectionAt` 标记一并写入本地档案，回读确认成功后才返回 `saved: true`。调用者只能在此结果为 true 后删除原会话的轻量印象。重复晋升不会增加消息互动计数。

## 两层信息
| 层 | 内容 | 去哪 |
| --- | --- | --- |
| 完整 info | 身份、会话、次数、全部备注、结构化字段 | 只在本机 `state/user-profiles.json`；当前发言者通过人物小档案组件注入 |
| 可分享 info | 脱敏后的喜好/趣事/名言 | 可以出现在别的会话的「别处听来的」段落 |

## 作息（固定块）
`fields.routines` 是一组短句数组，存的是本人明确说过的作息：三餐（时间＋可选口味）、起床/入睡、工作/上课时段，可标注“固定/大致”。人物卡渲染时由 `routineBlockLines()` 固定输出一块「作息」，有数据才出现、空的不占位；口味单独汇总成一行（来自三餐条目与食物相关的 likes/dislikes）。
- 只在本人的私聊 key 里渲染与使用，绝不跨会话、不发群；不从在线时间或语气推断。
- 到点附近可以顺口贴合一句，不催吃饭/催睡觉、不假定对方有空；刚聊完不叠加；临时变动写当前会话轻量记忆，不覆盖稳定作息。
- 兼容旧数据：旧的自由短句（如「早餐7:30左右」「工作 9:00-18:00」）照样能被解析、照常渲染，不做破坏性迁移。

脱敏规则：含 QQ/微信/电话/地址/密码/邮箱/身份证/银行卡等字样的、带 5 位以上数字的、联系方式形态的，一律不进可分享层。

## 边界
- 不判断「什么值得记」——那是 `profile-facts` 插件 + AI 的事。
- 不主动发消息；跨会话只分享可分享层，且禁止暴露来源。
- 桥接里不再保留第二份内存缓存：所有写入都走本插件，避免互相覆盖。
- 群消息登记就足以建立基本用户记录和人物卡，不要求先有私聊；`warmConnectionAt` 仅在对应群内人物卡表示明确的正向亲近，不作为数值好感评分。
