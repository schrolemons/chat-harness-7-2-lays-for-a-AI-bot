# skill：浏览器管理（exec-browser-manager）—— 双模

## 它解决什么
让 AI 既能**无人值守地监控/操控网站**，又能在**关键授权**时把窗口还给用户。
核心是两态切换，而不是一刀切「无头」或「可见」。

## 双模语义
| 模式 | 做什么 | 是否要用户 |
| --- | --- | --- |
| 无头（headless） | 监控、操控、只读抓取 | 否，复用本机登录态，不重登 |
| 可见窗口（visible） | 登录态激活、登录、验证码、购物结算、支付确认 | 是，用户看到并亲自操作 |

## 规则
- 无头复用本机登录态，不自动填账号密码。
- 关键授权弹可见窗口，AI 只负责打开窗口、指到这一步，不替用户点。
- 一次一页、慢一点、读结构优先，不批量翻页/爬取。
- 含身份证、银行卡、密码的页面不截图、不发内容。
- 节奏拟人：随机间隔、失败退避，防风控。
- 拿不准是不是关键授权 → 宁可弹可见窗口。

## 工具
`browser_policy`（只读）：返回 `headlessFor` / `visibleFor` / `rules`。

## 边界
执行仍在 Playwright MCP；本插件管策略与切换口径。登录态只在本机，绝不上传。
