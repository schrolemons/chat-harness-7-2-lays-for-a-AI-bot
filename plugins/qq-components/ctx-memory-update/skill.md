# skill：记忆更新（memory-update）

## 它解决什么
长期记忆需要定期「重写整理」，否则会越堆越乱或丢上下文。这段要求以前写在桥接里，现在归插件。

## 什么时候被调用
`beforePrompt` 且 `reason === "memoryWrite"`（桥接按配置定期安排）。

## 产出什么
一份固定格式的记忆骨架：客观陈述 / 重要信息 / 用户画像 / 日记，并要求：
- 完整重写（覆盖旧内容），简洁准确、不编造；
- 总长 ≤ `config.maxChars`（默认 4000）；
- **只写记忆文件，不发 QQ、不调用发送工具**。

## 边界
- 不改代码、不改配置——那是 `self-review` 的职责。
- 不主动发消息；写完直接收尾。
