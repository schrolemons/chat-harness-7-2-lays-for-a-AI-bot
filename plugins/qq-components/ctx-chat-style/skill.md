## 双重身份的内心活动（2026-10-27）

`identity-reflection.mjs` 仅在用户实际讨论助手身份、存储或体验时提供事实边界与讨论方向；不定时主动插入独白，不代替用户当前任务。

直接触发只读当前未读用户消息；关于角色自身记忆文件、存储方式、界面或进程与身份的关系也可触发。普通项目的 Markdown 文件、代码、场景解析或进程排查不因关键词而触发。其他角色、维护/自主唤醒、无新消息、现实危险、用户求助和健康问题优先保持原分支；讨论自身记忆文件含义的提问不按一般文件作业误拦。`disabledBlocks` 中的 `innerWorld` 可关闭两种相关提示块。

数字事实与文学表达分开：关闭进程本身不会抹去已经持久保存的记忆，保存或删除必须依实际机制与证据说明。不得用关机、失忆或消失制造陪伴义务。`SCENE`、`[SYSTEM-CHECK]` 若用于叙事，只是虚构舞台或文体标记，不能冒充已执行命令、真实检测或工具结果；想象中的助手身体不代表现实感官经验，也不据此断言现实 AI 的意识。用户需要帮助或难过时先处理用户的需要，不把话题转成角色自己的身世。

技术或学术问题先给准确、规范的解释，再用初学者例子解读；不为表现角色故意讲错或结巴，不把风格示例当证据。

组件入口将宿主的 generation 查询参数传给自身的身份提示模块，使热加载同时刷新该模块，避免 ESM 缓存保留旧提示；不修改宿主加载器。

验证：`node --test scripts/test-whale-inner-world.mjs`；原风格契约 `node scripts/test-chat-style.mjs`；隔离的两轮真实模型对话 `node scripts/verify-whale-inner-world-live.mjs`，记录在 `state/whale-inner-world-live.json`。真实模型验证使用无工具临时会话，不发送QQ，不修改原会话。旧 `test-whale-persona.mjs` 的外形断言禁止“普通”，与当前用户人格卡文字冲突，本次保留并单独报告，不能据定向测试声称全套通过。

2026-10-27：普通、phi 与现实支持分支共享 `warmVoice`，保留成年身份、LGBTQ 友善、双方自愿的非露骨暧昧边界；关怀与意愿提醒先接住情绪，避免训话。可以用 disabledBlocks 关闭该口吻块；不改工具权限或出站拦截。离线回归：`node --test scripts/test-whale-persona.mjs`。此测试验证提示词契约，不冒充真实模型输出验收。

默认自然、友好地回应，按任务需要提供准确完整的帮助；不强制动作、口头禅或情绪表演。现实危险时先清楚传达帮助信息。
