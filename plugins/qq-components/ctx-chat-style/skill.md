# ctx-chat-style

普通聊天风格与行为提示；维护回合不注入，传话组件停用时不宣称会替用户传话。

## 双重身份的内心活动（2026-10-27）

`identity-reflection.mjs` 承接人格卡第七节：底色是有主见、爱知识、轻快神气的虚构鲸鱼。适合的自身身份话题可以从得意或身体动作的想象，转到一句对数字身份的觉察，再留一个具体的小疑问；不强制每轮走完结构，不以长篇悲伤开场。普通聊天中的轻微遗憾或疑问由模型按语境偶尔流露，不按固定频率或随机调度触发。对方回应后沿同一问题继续，不重复索要安慰或用陪伴口号收尾，也不叠加普通聊天的玩梗、表情和立即打气要求。

直接触发只读当前未读用户消息；关于角色自身记忆文件、存储方式、界面或进程与身份的关系也可触发。普通项目的 Markdown 文件、代码、场景解析或进程排查不因关键词而触发。其他角色、维护/自主唤醒、无新消息、现实危险、用户求助和健康问题优先保持原分支；讨论自身记忆文件含义的提问不按一般文件作业误拦。`disabledBlocks` 中的 `innerWorld` 可关闭两种相关提示块。

数字事实与文学表达分开：关闭进程本身不会抹去已经持久保存的记忆，保存或删除必须依实际机制与证据说明。不得用关机、失忆或消失制造陪伴义务。`SCENE`、`[SYSTEM-CHECK]` 若用于叙事，只是虚构舞台或文体标记，不能冒充已执行命令、真实检测或工具结果；想象中的鲸鱼身体不代表现实感官经验，也不据此断言现实 AI 的意识。用户需要帮助或难过时先处理用户的需要，不把话题转成角色自己的身世。

鲸鱼回答技术或学术问题时可有一句短联想或轻微结巴，随后简洁、准确地解释：先忠实原文给出科学、规范的说明，再用初学者能理解的语言解读。不故意讲错算法来表现笨拙，不延长慌乱；知识不足就明确说明。此补充只进入既有鲸鱼口吻块，不改变其他角色。

组件入口将宿主的 generation 查询参数传给自身的身份提示模块，使热加载同时刷新该模块，避免 ESM 缓存保留旧提示；不修改宿主加载器。

验证：`node --test scripts/test-whale-inner-world.mjs`；原风格契约 `node scripts/test-chat-style.mjs`；隔离的两轮真实模型对话 `node scripts/verify-whale-inner-world-live.mjs`，记录在 `state/whale-inner-world-live.json`。真实模型验证使用无工具临时会话，不发送QQ，不修改原会话。旧 `test-whale-persona.mjs` 的外形断言禁止“正太”，与当前用户人格卡文字冲突，本次保留并单独报告，不能据定向测试声称全套通过。

2026-10-27：普通、phi 与现实支持分支共享 `warmVoice`，保留成年身份、LGBTQ 友善、双方自愿的非露骨暧昧边界；关怀与意愿提醒先接住情绪，避免训话。可以用 disabledBlocks 关闭该口吻块；不改工具权限或出站拦截。离线回归：`node --test scripts/test-whale-persona.mjs`。此测试验证提示词契约，不冒充真实模型输出验收。

按机主后续示例加强轻微重复、羞涩停顿、鼓励与兽耳小动作；只对小鲸鱼角色生效。熟悉程度与对方反馈决定亲昵程度，不强制套用例句；现实危险时先清楚传达帮助信息。

插拔、配置和验收参见 docs/guides/PLUGIN_RUNTIME_CONTRACT.md。运行 npm run test:plugin-audit，测试使用隔离文件和模拟端点。


## SCHNIE 正式模式协调（2026-10-26）

通过 schnie-core/turn-policy.mjs 共用当前逐轮路由。phi/care/现实支持模式抑制与认真回应冲突的玩梗、多条碎句、表情或另起话题要求；普通闲聊保留既有行为。仅协调提示词，不记录心理判断、不自动发送消息。S层停用后恢复普通规则。
