保存模型生成的自定义游戏

模型可根据你的描述生成受限 JSON GameAdapter；粘贴完整 JSON 后保存。此适配器只允许声明初始状态、动作输入和 set / increment / randomInt 转移，不执行 JavaScript。

games_catalog查看已启用游戏、规则与参数。
games_create按用户描述生成并校验受限 JSON GameAdapter，保存为自定义游戏。
games_start开始已启用的任一游戏；小火花要求参与者本人明确同意。
games_action执行内置玩法或自定义 adapter 声明的合法动作。
games_status / games_stop查询或结束当前互动；拒绝、不适或要求停止时立即结束。
