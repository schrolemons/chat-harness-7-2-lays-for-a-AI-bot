主动行为

L定时主动消息（timeBubbles：按会话配置时段）

此会话时段 · 只保存选中会话的时段与锁定状态；全局数量上限单独保存。

例：选择一个会话：只编辑这个会话的时间冒泡，切换会话不会复制排程。
锁定后鲸鱼和控制台均不能改时段；取消勾选即可解锁。
每个会话独立配置；列表为空或没有配置时，不发送时间冒泡。添加时段即开始按时提醒。
L话题跟进（全局策略与私聊 session 限制）
单独设置私聊会话限制选择目标私聊后，可设置更严格的跟进频率；留空继承全局值，最终采用全局与单会话限制中较严格的一项。
例：选择private:10001：编辑这位好友的私聊跟进限制。
例：设为90：该私聊跟进至少间隔90分钟；若全局要求更久则取更久值。
例：设为1：这位好友每天最多跟进1次；不能通过局部值放宽全局上限。

抽样规则：主题权重 = 基础权重 1 + 该主题关联 UP 权重总和；主题概率 = 该主题权重 / 全部主题权重之和。选中主题后，关联 UP 的抽中概率 = 该 UP 权重 /（基础权重 1 + 同主题关联 UP 权重总和）；抽中基础权重时搜索新的 UP 主。
视频规则：抽中关联 UP 后先按“主题 + UP 名”搜索；若找到与主题相关且信息可核实的视频，推荐中至少包含 1 条该 UP 视频。只有定向搜索没有合格结果时，才全部用其他 UP 补足；其余条数仍可选名单外更热门、更有意思或更贴题的视频。抽中基础权重时广泛搜索新 UP 主。
