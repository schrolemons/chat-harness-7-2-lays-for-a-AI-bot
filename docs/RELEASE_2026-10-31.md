# 控制台与桥接同步

本次同步控制台、上下文可视化、发送限额、工具和桥接的共用实现。上下文继续按内容来源分模块，实际请求与QQ发送记录分别呈现；生成文本不能冒充已投递消息。满额群聊的机械回复仅针对真实点名或核实引用，保留发送限频。

余额监控设置在O层→调试与运维→桥接控制，与健康巡查及桌面便签放在一起。富足、偏少、见底三个金额和提醒范围可设置；当前档位、前后净变化及相对增幅作为事实提供给模型，聊天反应由角色与心情提示词生成。具体接口与边界以[组件说明](../plugins/qq-components/tool-deepseek-balance/skill.md)为准。

私聊与群聊的真实会话令牌决定查询身份，不能自报管理员。非管理员结果不包含账户金额。相同调用额度事件的桌面便签跨会话去重，真实进程每次启动记录一次，热载不重复。

公开分发不含运行状态、真实聊天/人物资料、角色私人约定、个人知识原文、凭据、登录信息或本机审计记录。S层仅保留通用接口及独立的虚构示例，默认未挂载。监控域名与示例称呼已通用化；本地使用者自行配置目标和资料。

安装器保留现有profile与会话，重复安装不重复注册网页摘要预设。分发检查覆盖全部静态本地导入、空配置安装两次、默认未挂载资料、控制台构建和隐私扫描。

公开模板的角色卡、形态示例、机械回复、拍一拍、冒泡、启动问候和余额说明均使用中性 AI 助手设定；私人语言示范不包含在发布内容中。
