# 2026-10-30 会话策略与控制台更新

- “话题发起与跟进”区分群聊转私聊跟进和当前会话的话题行为。前者独立使用最小间隔及每日上限，后者使用同话题冷却、新话题冷却与每小时新话题上限。
- 私聊、群聊均先按无人回复收尾概率 p/q 判断是否结束；继续本轮后，再按 a、b、1−a−b 选择追问旧话题、开启新话题或继续等待。默认 p=50%、q=25个百分点，a=0.5、b=0.2。参数均可编辑。
- 冷却或次数限制不满足时转为等待，不重新抽签。只有实际发送成功才消费次数，分条发送按同一波去重。话题发起和跟进会刷新主动会话状态，但不会重置无人回复计数；新来信才重置。
- 等新消息和等对方说完使用独立工具。结束本轮时撤销旧话题发送授权，仅停止当前回合，保留会话、历史和新来信。
- 聊天意愿是对用户忙闲与精力的客观评估，须说明依据；心情是 bot 的主观交流感受，独立决定语言风格。收发消息不再机械加减聊天意愿。
- 共用缩放系数 F=(0.2+0.8×心情/100)×(0.2+0.8×聊天意愿/100)，影响主动概率、条数和深度；现有宵禁、免打扰、预算和发送上限继续生效。
- 控制台按功能拥有源组织页面，环境监控与脚本协作状态可追踪。图片生成统一使用 OpenAI 兼容接口配置。

公开版保留独立浏览器、可配置的通用监控及可重复安装机制，不携带本机课程自动化、登录态、私人参考资料、人物档案或群内约定。角色文件是可编辑的虚构示例。测试使用隔离状态与模拟网关；通过测试不代表生产 QQ 消息已实际送达。
