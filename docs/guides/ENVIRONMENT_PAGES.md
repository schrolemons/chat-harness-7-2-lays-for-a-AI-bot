# E 层栏目与保存范围

原“环境与执行”总页已拆除，入口只保留一份。

| 栏目 | 内容 | 保存范围 |
|---|---|---|
| 普通聊天环境 | 传话组件 | 原传话组件配置 |
| 管理员环境 | 管理员开发开关、开发预设 | `adminDev`，只影响管理员私聊 |
| 网站操控 | 通用网页访问范围 | 浏览器组件的 `allowUrls/blockUrls` |
| 网页监督 | 监控网址、检查间隔、登录恢复与状态 | 网站清单和监控参数，浏览器规则独立保存 |
| 脚本协同 | 脚本清单、逐项启停、心跳和协同约定 | 保存脚本清单，保留网站设置和协同约定 |
| 图片 | OpenAI 图片接口、模型、额度、本机密钥、用量 | 普通配置与密钥分开保存 |
| 视频 | 预留入口 | 没有开关或假参数，尚未接入服务 |




图片生成只保留 OpenAI 一组配置，不再选择供应商，也不读取 Ark 密钥。一次性清理脚本 `node scripts/migrate-image-config-openai.mjs --apply` 备份普通配置后移除退役字段；不修改密钥文件。服务局部热加载，不需要重启桥接或 DSH。

验证：`node scripts/test-environment-pages.mjs` 检查导航、管理员保存范围、浏览器字段归属、OpenAI 密钥界面和三档宽度；`node --test scripts/test-image-generation.mjs` 使用模拟请求检查生图、参考图、额度与密钥隔离，不产生真实 API 费用。
