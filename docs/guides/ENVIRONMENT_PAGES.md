# E 层栏目与保存范围

原“环境与执行”总页已拆除，入口只保留一份。

| 栏目 | 内容 | 保存范围 |
|---|---|---|
| 普通聊天环境 | 传话组件 | 原传话组件配置 |
| 管理员环境 | 管理员开发开关、开发预设 | `adminDev`，只影响管理员私聊 |
| 网站操控 | 通用网页访问范围 | 浏览器组件的 `allowUrls/blockUrls` |
| 网页监督 | 监控网址、检查间隔、运行方式与规则、读取状态 | 监控参数与浏览器的 `headlessFor/visibleFor/rules` 分别保存 |
| 脚本协同 | 只填写脚本地址、逐项启停；每项下方一行只读执行与搜索约定 | 只修改脚本清单，保留后台约定及网址设置 |
| 图片 | OpenAI 图片接口、模型、额度、本机密钥、用量 | 普通配置与密钥分开保存 |
| 视频 | 预留入口 | 没有开关或假参数，尚未接入服务 |

浏览器运行场景与通用规则移到网页监督里，DOM 页面不重复显示。两个浏览器表单仍由同一组件拥有，按字段合并保存；监控页不复制组件启停开关。

组件主体始终展开。网页监督的“调整监控参数”“浏览器运行方式与监控规则”等参数分区默认展开，使用边框、左侧箭头及“展开／收起”提示；支持键盘操作。监控条目将名称、可换行的网址、检查时间和四项状态（读取、访问／登录、内容变化、通知发送）分开显示，不重复堆放正常提示，也不展示讲座检查说明。

脚本协同不展示地点、讲座接口等专用参数。开发者与 AI 确定执行／搜索约定后，在 `life-campus-watch` 配置的 `scriptDescriptions` 中按脚本地址保存一行说明；控制台只读展示，不提供第二套编辑表单。没有约定时如实显示“尚未记录”。全部取消勾选会暂停协同；仅登记地址不会自动执行脚本。保存后立即重新读取状态和说明，停用条目仍保留其说明。

图片生成只保留 OpenAI 一组配置，不再选择供应商，也不读取 Ark 密钥。一次性清理脚本 `node scripts/migrate-image-config-openai.mjs --apply` 备份普通配置后移除退役字段；不修改密钥文件。服务局部热加载，不需要重启桥接或 DSH。

验证：`node scripts/test-environment-pages.mjs` 检查七个导航、展开箭头、管理员保存范围、浏览器字段归属、OpenAI 密钥界面和三档宽度；`node --test scripts/test-image-generation.mjs` 使用模拟请求检查生图、参考图、额度与密钥隔离，不产生真实 API 费用。
