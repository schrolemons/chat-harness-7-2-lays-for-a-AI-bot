# 日记与主动聊天意愿

聊天意愿与心情分别更新。长时间未获回应会逐步降低有效意愿，默认下限为1；保留原概率增长模型和检查间隔，在最终主动开口概率上乘以有效意愿与基础意愿的比值。连续联系次数仅用于记录，不构成禁止模型说话的硬条件。

日记白天按更新间隔加0—50%的随机错峰时间，并结合新增真实来信更新；下一次时间持久保存，重启不会重新抽取，保留早、中、晚已有片段。22:00重新整理当天过程、感受与看法，再归档和统一投递。独立日记整理器直接输出正文，不再要求单字段JSON包装；事实和画像工具仍使用各自原有结构。正文选择有意义的变化进行高度总结，不逐条复述聊天、不只看晚间消息，也不让昨天的经历主导今天的日记；资料不足时保持简短，不虚构缺失时段。当天本会话没有真实用户发言时不自动生成新日记。

补发仅使用对应会话和日期已经存在的历史归档，发送成功须有统一投递回执；未知结果不会自动重放。隔离回归使用合成资料，不能替代真实定时投递验收。
