# 发布与运行数据边界

本仓库由代码白名单重新导出，建立新 Git 历史，不带原运行目录或原提交历史。

发布前检查的内容包括：个人会话标识、用户目录、凭据、实际监控目标、私人知识卡、个人自动化、浏览器状态、日志、截图、备份与实际验收记录。Codex Peer 只提供通用实现，没有既有会话、设置、thread ID、viewer 令牌或工具结果。

`state/`、`config.json`、`campus-watch.json`、`browser-sites.json`、`.env*`、`user-scripts/`、`private/`、浏览器资料和依赖目录均为本机数据。配置示例为空白或保守默认值，首次启动生成自己的令牌。

S 参考目录只有一个新编写的公开教学示例；并不包含作者的哲学原稿、生活素材或私人目录。形象图片是通用占位图，真实图片由使用者自己提供。

`npm run privacy:check` 检查 Git 中已登记及未忽略的文件；对尚未初始化 Git 的目录检查发布文件树。它会拒绝运行数据路径、未审查的二进制、典型凭据和个人目录字面量。不要通过把整个源码目录加入扫描白名单来“解决”警告。

模型整理网页内容时，会将选中的网页差异发送给使用者所配置的 DSH 模型服务；Codex 咨询也使用自己的 Codex 服务。不要为没有权利处理的数据开启这些功能。浏览器登录在独立的本地 profile 中完成，不导出或上传 Cookie。

新增组件仍需要人工审查。扫描通过代表本次规则检查未发现问题，不代表任何未来文件都能自动安全发布。
